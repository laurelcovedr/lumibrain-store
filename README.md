# LumiBrain™ Store

Consumer wellness storefront for YIWEI Medical Technology Co., Ltd.

## Run locally

Serve the `dist/` directory with any static web server, for example:

```sh
python3 -m http.server 8000 --directory dist
```

Languages: English, Brazilian Portuguese, Spanish and French. The site includes product and research pages, PayPal hosted-button integration, and delivery details sent through the visitor's email application.

## Payment status

PayPal button KZPW6SPBU9VSG is configured in USD. Demo partner codes do not modify PayPal payments or create live commissions. Automatic payment verification, order storage, subscription activation and post-payment redirects are not implemented.

Product imagery includes AI-generated illustrations. Final hardware configuration is subject to delivery.

This repository is a snapshot of the hosted website, not an automatic two-way synchronization.
